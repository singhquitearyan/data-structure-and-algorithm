Given a decimal number as input, we need to write a program to convert the given decimal number into an equivalent binary number. 

Examples : 

Input: d = 7                                                         
Output: 111
Explanation:  20 + 21  + 22 = 1+2+4 = 7.

Input: d = 10
Output: 1010
Explanation: 21  + 23 = 2+8 = 10.
